# GMG Equilíbrio — Landing page

Landing page de produto para a **GMG Equilíbrio**, um suplemento em cápsulas. A página apresenta o produto, os ativos da fórmula, a rotina de uso e depoimentos, conduzindo o visitante até a compra.

🔗 **No ar:** [gmg-site-beta.vercel.app](https://gmg-site-beta.vercel.app)

## Destaques

- Página única com seções de apresentação, fórmula, rotina de uso, depoimentos e chamada final
- Animações de entrada e de scroll com **GSAP**
- Identidade visual própria definida em variáveis CSS (paleta ameixa/magenta/cítrico, tipografia Fraunces + Manrope)
- Layout responsivo e foco visível para navegação por teclado
- 100% estático, sem etapa de build

## Tecnologias

HTML5, CSS3, JavaScript, GSAP, deploy na Vercel.

## Como rodar

Abra o `index.html` no navegador ou sirva a pasta com:

```bash
npx serve .
```
